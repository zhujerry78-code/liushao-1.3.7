# 旧版复核迁移

顺序：解压 r11 到全新本机可写目录 → 双击 `5_迁移旧版复核.cmd` → 迁移成功后双击 `1_一键安装并启动.cmd`。

1. 先关闭新旧流哨。选择旧版 r10 或 r11 文件夹；默认读取其中的 `demo-state/reviews.sqlite`，自定义旧库可输入其完整路径。
2. 核对显示的旧库，确认没有其他程序写入后输入 YES。迁移入口不会自动搜索、合并、结束进程或覆盖已有目标。
3. 新目标固定为新目录的 `demo-state/reviews.sqlite`。目标只要已存在就停止，包括第一次启动建立的空库；请换全新解压目录。若设置了指向其他位置的 `LIUSHAO_REVIEW_DB`，先核对并清除该设置。
4. 程序以 SQLite 只读备份复制已提交记录，包括 WAL 内容，核验历史与自增ID后保存新库。失败保留旧库与已有目标，只清理本次临时文件。
5. 启动 r11，以原来的输入方式重新检查：旧版用“内置演示数据”的仍选择内置演示；旧版上传文件的重新上传相同文件。上传 demo.csv 与使用内置演示的记录ID不同。

复制的是已保存复核历史。原输入、未保存草稿、浏览器资料和恢复缓存不会迁移。不同模型版本的记录原样保留，但当前页面只显示当前模型及输入对应的复核。

回退时继续使用保留的旧目录；新版后续新增操作不会自动合并回旧库。操作记录 JSON 仅供留档，不能替代 SQLite 备份。

本版新增版本化证据侧表。迁移分别识别原六列库、已知工作增量侧表和本版目标结构，核验每份快照的关联与哈希后，在新目标库中升级。旧记录没有当时快照时不补造；未知结构与校验失败会停止迁移。
