# 复核与评分说明

双击 `1_一键安装并启动.cmd` 后，流哨会自动打开专用浏览器窗口，并等待页面返回就绪回执。专用配置按安装目录隔离，保存在本机用户目录。服务已运行但页面尚未就绪时，按启动提示处理；不需要手工复制网址。以后使用 `2_启动流哨.cmd`。

`4_关闭流哨.cmd` 停止本目录服务；仍显示的专用窗口可直接点右上角关闭。普通浏览器和其他安装目录保留。若仍出现灰色空白，请保留启动日志，不要通过关闭浏览器安全沙箱处理。

在“查看结果”选演示或上传 CSV，点击“开始检查”，然后进入“检查记录”。

在上方列表选一条记录，下方会显示两种模型（RF、LR）的分数。“我的判断”上方单独列出“这条记录需要你核对”，把本条的当前值、对照参考和具体需查什么放在同一区域。先看本条有哪些现象，再按提示找对应日志、资产用途和同一时间段的记录。没有可用参考或原始数据时，页面会说明缺少什么；不能靠猜测补齐。

桌面端图与填写区域并排，窄屏上下排列。分数只用于帮助安排核查，不能当成这条记录发生攻击的概率。备注建议写清查了哪份日志或哪台资产、时间范围、看到了什么，以及还缺什么。确认正常或异常必须填写依据；材料不足时可保存“需要补充信息（待补证）”。保存成功后才会前进到下一条。

需要查看分数从哪里来时，点击“查看完整评分依据”。详情有“评分图解”“证据明细”“原始数据与方法”三个标签页。页面只展示当前记录实际有的依据，可能少于六项，也可能没有。点击“返回复核”会保留当前记录、筛选、检索、页码、判断和未保存备注。打开或返回详情都不会自动保存。更换输入文件或模型后，要重新检查。操作历史默认收起，需要时再展开。

“快速检索”按来源行号精确匹配数字，也可查主表显示的系统提示和我的判断。匹配记录在当前筛选范围内置顶，其他记录保留。回车应用，清空恢复；切页和查看解释保留填写。

“评分图解”像一张分数账单：它说明哪些数据把分数推高或拉低。RF 从一个起始分数开始，加上全部字段的影响后，得到本条 RF 分数；图中默认最多列12项，剩下的合并为“其余项合计”，也能展开查看。这里的影响大小用“概率点”表示，例如 0.01 就是分数相差 1 个百分点，不代表攻击可能性增加了 1%。

LR 的算法不同：先把处理后的各项数据乘以各自权重，再加一个固定起始项，最后经过曲线换算成 0 到 1 的分数。详情中出现的“截距”“线性项”“对数几率”是这一步计算的名称。RF 与 LR 是两套计算结果，分数和字段影响不能相加；各项正负影响也不是加起来等于100%的风险占比。“改一项再算”只表示单独替换一项数据后分数怎样变化，多项结果不能直接相加。

“参考”来自训练时的正常样本，不能直接当作你本地网络的正常范围。P01、P50、P99 分别表示这些样本从小到大排到约1%、50%、99%位置的值，用来帮助比较。落在范围内不能保证正常，超出范围也不能证明攻击，靠近范围边缘同样不表示高风险。协议、连接标志和端口要结合它们的实际含义、资产用途和日志检查，不能只比数字大小。原始数据缺失、读取时被清理为缺失、模型后来填入的值会分别列出，避免把填入值当成原始观察。

详情里用于挑选重点和提示变化的规则，仍需通过实际使用验证。具体包括：单项影响达到0.01才重点展示、合计影响0.10、稳定性50%、参考调整10%、范围边缘5%；LR 还用1e-6作为识别变化方向的最小差值。这些是展示和解释用的工程规则，不是已经证实有效的攻击判定标准。若页面提示不同试算结果不一致，实际影响仍待评估。账单能与最终分数对上，只说明计算能够核对，不能证明发生了攻击。

点击保存时，你的判断、备注和当时对应的证据一起写入历史，旧操作会保留。旧版只有六列的历史记录不会补造当时的证据。可以按操作ID查历史；导出的操作记录JSON保留本次检查、当前模型版本下的全部已保存操作。复核结论单只收录最新的确认结果，优先使用保存当时的证据；旧记录如果没有当时证据，会明确标出。

下载页分别说明检查结果CSV、操作记录JSON、运行信息JSON的用途。三种文件取自同一次准备好的结果，方便互相核对；列表的筛选、分页、检索不会减少导出范围。因文件数据问题而无法判断的记录，可到“文件问题”单独下载。

迁移请先关闭新旧流哨，把新版解压到全新目录，并在首次启动前运行“5_迁移旧版复核.cmd”。迁移会复制旧库，保留原记录ID和历史；不能识别的数据库结构或无法核对的证据会阻止迁移。直接打开旧库发生首次升级时，会留下 before-evidence-v2.bak 原库备份，请保留。

本机自动测试和浏览器操作检查，只能说明相应工程环节是否通过。本版尚未证明这些提示能让真人更快、更准地复核，也没有完成实用阈值标定或“30秒说清问题”的真人验证。


## 白盒区间与评分线索

核查表把当前值、训练正常参考和评分影响放在一起。RF 路径贡献说明本条分数由哪些加减项组成；常见值对照变化说明只将一个字段换成参考中间值后，RF 分数如何变化。两者计算方式不同，可以出现相反方向，不能混用，也不能将多项替换变化直接相加。

连续字段有有效的 P01、P50、P99 参考时，页面区分“显著偏离参考”（超出范围的距离大于一个 P01～P99 跨度）、“超出参考范围”、“接近参考边界”和“参考区间内”。近边界在低侧按 P50-P01、高侧按 P99-P50 计算到边界距离，不超过对应侧跨度的5%才标注；P50及零宽侧不判近边界。这不是经验尾概率。这些是数值位置描述，不是攻击风险等级。“显著偏离”包含在“超出参考”总数中。原始缺失、参考不足、离散编码和固定参考单独处理，不会当作正常区间内。无效或非有限原值按缺失处理。

缺失字段的替换试算同时改变数值与缺失指示状态，卡片明确标注“替换试算包含缺失状态变化”；不能把这项变化解释成缺失项的原值贡献。1.3.6解释方法版本为review-evidence-v2.3，历史快照保留原版本及原数据，不自动重算。区间定位与特征单位使用liushao纯库规则；TotLen Fwd Pkts与TotLen Bwd Pkts均以字节（B）显示。

评分线索使用全部达到 0.01 展示条件的 RF 正路径贡献字段，逐项核对其参考；不会只检查前几项就概括全表。只有这些字段全部具有可比较的连续参考、均在区间内、至少两项且这些字段的贡献合计达到 0.10 时，才提示多项区间内字段共同推高。该合计仅表示分数账单中的加法关系，不证明特征协同或攻击成因。缺少分数、分界值或评分分解时，页面明确显示不可用，不补造正常判断。

客观摘要先预览，再追加到现有备注中，不会自动保存或覆盖已有核查记录。摘要明确标注为自动整理草稿，含当前记录 ID、可用分数、区间统计和待查事项。它不表示已经查阅外部日志；人工确认仍需补充实际核查依据。没有可展示明细时，不会写成“没有偏离”或“已核对”。

“整批数据分析”保留全字段区间分布和 CSV 下载，用于找出本批数据中需要核对的字段。训练正常参考不能直接作为当前网络的正常标准，整批越界比例同样不代表攻击率。
