# 流哨模型卡

用途：离线检查格式匹配的网络记录，提供模型提示、证据查看和人工复核留痕。模型提示用于辅助查看，人工确认必须填写依据。

- 默认冻结模型：c7a028b4e4cafedd。RF 主判、LR 对照，77 个输入特征。
- RF 阈值 0.12、LR 阈值 0.84；阈值在验证集选择后冻结，页面不调整。
- 训练 161,331 条、验证 21,468 条、留出测试 15,519 条。来源为 CSE-CIC-IDS2018 的 2018-02-16 与 2018-03-02 文件。
- 留出集正常 13,532、Bot 1,986、SlowHTTPTest 1；RF F1 98.61%，误报 56、漏报 0。Hulk 没有测试支持数。
- 划分为同来源、同采集日的分组留出；不构成来源独立或未来时间验证。
- 固定跨采集日 2018-02-15 场景中，RF F1 59.20%；GoldenEye 检出 26,142/41,508，召回率62.98%；Slowloris 检出165/10,990，召回率1.50%。场景同时改变采集日、两类未见攻击及攻击占比（12.80%降至约5%）；指纹重叠是数据边界，不能据此认定它是落差的主要原因，也不能宣称全面检测或部署效果。
- 分歧与近阈值提示用于复核。原组合未优于所有合理固定预算基线，不能声称分类提升或真人节时。
- P01/P50/P99 是训练正常参考；本批百分位是当前整批有限、未填补观测的相对位置，并列值取中间位置。两者都不是攻击概率或因果解释。

模型与评测页展示配套历史摘要及支持数，须与当前模型、描述和数据版本匹配。发行包启动前校验全部登记文件，包括摘要、六份历史来源和复评报告；缺失或损坏时拦截启动，请保留复核库并重新完整解压原包。运行中的评测读取还会核对资料身份，读取失败时隐藏相关指标并提示原因。

## 测试集构成与有效样本量

进入训练、验证、测试的非剔除记录共198,318条，测试15,519条，占7.83%；测试攻击占比12.80%，其中Bot占99.95%；训练攻击占比46.07%。测试只有11个来源文件与15分钟观察块，其中6块含攻击（5块含Bot，另1块仅有1条SlowHTTPTest），不能将15,519条视作同等数量的独立样本。

1.3.5独立恢复原数据与原划分，用同一冻结模型重新推理，不训练或调阈值。新评测与历史六份来源分开保存。F1等区间采用固定种子20261017、2000次整块重采样；准确名称为“基于11个观察时间块的条件95%重采样区间”，区间见评测页及独立复评包。跨块相关仍可能存在，零漏报形成的退化区间不保证未来100%召回。

本轮RF F1为98.61%，条件95%重采样区间96.48%～99.25%；LR F1为96.51%，区间92.95%～97.50%。两模型混淆矩阵与原历史记录一致；固定种子下2000次各指标均有定义。
