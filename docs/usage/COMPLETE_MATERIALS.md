# 完整材料与离线重建

完整材料包在运行包、源码包之外，提供同一版本重建需要的原始资源 ZIP、固定评测摘要、源码清单摘要、操作入口和逐文件 SHA256。运行包与源码包仍可分别使用；完整材料的日期与软件首次固定的发行日期可能不同，请以完整源码 SHA 和清单绑定版本。

## 操作顺序

完整解压到较短的本机可写目录，不要在压缩软件预览窗口内运行。

1. `1_准备运行文件.cmd`：核对材料哈希并展开本次运行包，不创建复核数据库。
2. 有旧复核时，使用 `2_迁移旧版复核.cmd`。迁移必须在新包第一次创建数据库前完成；选择旧版目录，原库保留。详见[迁移说明](MIGRATION.md)。
3. `3_安装并启动.cmd`：使用包内 Python 和本地 wheel 离线安装并打开软件。
4. `4_校验全部材料.cmd`：重新核对材料清单及运行包的静态文件；用户后续产生的复核、输入及草稿不属于发行文件。
5. `5_从源码重建.cmd`：使用包内环境、独立源码和原始资源重新生成运行与源码 ZIP，并与交付 ZIP 的 SHA256 比较。输出目录已存在时停止，不覆盖。

重建不训练模型，不从网络补文件，不复制现成虚拟环境。完整源码清单及材料清单不是数字签名，仍须核对另存的外部摘要。完整 Git 历史保护门禁需要原工程克隆；源码快照自身用于独立重建，完整工程门禁结果在配套验收材料中按提交记录。

“查看结果”将分数图与文件问题摘要并排展示；窄窗口自动上下排列。分数图默认使用对数数量刻度展开小柱，可切换线性数量，悬浮显示准确条数；分数区间与模型判断分界保持原含义。人工确认数为零时显示“尚未开始检查”，保存确认后更新进度。评测页的历史时间使用中文日期时间并明确 UTC。

## 目录与材料版本

- `01_软件`：本次运行 ZIP，含固定模型、演示资源、Python、离线依赖和必要许可。
- `02_源码`：对应源码 ZIP 和独立源码清单摘要。
- `03_重建资源`：构建器校验过的原始资源 ZIP 与评测摘要，只供重建读取。
- 说明、验收与截图：对应本次完整提交。工程合成记录不是真人试用。
- 既有 PPT、试用材料：按各自原版来源标识，不把历史画面、测试人数或旧测试数量改标为本次代码的结果。

文件目录 CSV 记录用途、来源版本、大小和哈希。清单及哈希文件自身以 `MATERIAL_MANIFEST.json` 为准；该 JSON 自身以材料包外的独立摘要为准。

## 数据与使用边界

运行包不包含用户复核库、上传缓存、WAL/SHM、迁移临时文件、浏览器资料或实际用户导出。历史试用附件只按明确清单收录原件，不改写记录，也不补造缺失时间或观察。

模型提示、当前分析证据、历史复核与本批相对位置含义不同。参见[模型卡](MODEL_CARD.md)、[本地文件说明](LOCAL_DATA.md)及[许可范围](../release/SOURCE_LICENSE.md)。
