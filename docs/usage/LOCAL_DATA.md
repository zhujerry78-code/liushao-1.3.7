# 本地文件与使用边界

程序在本机回环地址运行，安装使用包内离线依赖，Streamlit 使用统计关闭。输入在本机处理；这不表示用户上传的文件或填写的备注一定不含个人信息。

## 输入与保存

上传支持 UTF-8 CSV，最大 50 MiB、50,000 条记录。预检检查文件结构，不提前判定数据质量；正式分析后区分填补后可判断与无法判断。额外列不参与新增证据展示，标签不参与预测。

默认不把上传文件保存到恢复缓存。勾选“在本机保留此文件，便于下次继续”后，成功分析才保存最近一次勾选的文件。新上传重置勾选；取消勾选只撤销本次保存，不删除旧副本。“清除已保留文件”撤销恢复入口并删除副本，删除失败会提示清除未完成。

恢复缓存位于复核库旁的 `<数据库文件名>.last-session`。内置演示和合成格式练习不写入这份缓存。恢复核对输入 SHA 与当前模型身份后重新分析，不恢复旧预测、旧下载或未保存填写。

运行包复核库为 `demo-state/reviews.sqlite`；源码为 `data/reviews.sqlite`。`LIUSHAO_REVIEW_DB` 可指定其他库。复核行按模型版本与记录ID隔离；关联的保存时证据快照包含当时的模型、输入与描述 SHA256。历史快照按保存内容读取，不以当前模型重算替换；请勿用同版本异权重替换模型。

## 下载

- 检查结果 CSV：当前输入全部可判断记录，包含系统提示及最新保存的复核。
- 操作记录 JSON：当前输入的已保存历史，可能一条记录有多次操作；不是可导入备份格式。
- 运行信息 JSON：输入、模型与运行边界。
- 复核结论单 CSV：只含最新确认正常或确认异常；证据摘要来自保存时快照，原复核保存时间与结论单生成时间分列。旧记录无快照时明确标注缺失，不追认为当时证据。

这些文件在点击“生成下载文件”时使用同一快照，不受列表筛选影响。继续编辑后须重新生成。无法判断记录在文件问题页单独下载；不能计为正常。

复核备注、上传缓存、数据库及实际导出不随发行包分发。诊断包使用固定白名单，不收集上传内容或复核数据库。原文件仍可能保留在你原来的目录中，清除缓存不会删除原文件。
