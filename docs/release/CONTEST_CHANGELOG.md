# 1.3.7 / r13-contest 应用变更

日期 2026-10-29。基准是原 1.3.7 / r12-engine 的内容快照 `84331c3ad86888b49601a47ae32e6b6eb7ec7f14`；原包将其放在 source_commit 字段，本版明确标记它是内容快照，不声称是新建 Git 提交。

产品版本继续使用 1.3.7；r13-contest 是本次内部构建标识，r13-exact-va-v1 是应用推理身份。整改期间曾误把内部候选副本标为 1.3.8，本次仅更正版本元数据、显示与发布说明，不升级产品版本。既有功能修复、冻结模型和推理方法均保留。原候选副本及其真实日志留在外部工作目录，没有改写版本或混入当前交付；[版本映射与等价性记录](../results/contest_version_identity.json)分别列出历史验证事实和本次新执行的定向验证。

## 修复

1. 分析结果绑定引擎参数 SHA256、描述 SHA256 和应用推理版本。载入使用已经校验的同一份内存字节；缓存区分参数及描述身份。
2. 复核快照增加完整 13 个引擎字段、三源质量分配、阈值、完整 ECOD 贡献和身份。UI、保存和导出共用该证据。历史只读保存值；旧快照明确说明缺少引擎证据。当前引擎与原分析身份不同会拒绝保存，避免混用。
3. ECOD 面板从逐字段左右尾最大值改为实际最大总和获胜分支的贡献。全部字段加总还原原始分数；前六项只是展示摘要。冻结的旧 ecod_explain API 保留供历史复现，本版面板不再把它当作可加总分解。
4. 旧 VA 网格插值存在较大端点误差。本版从同一冻结共形 B 类别分数恢复校准样本，逐查询分数附加标签 0/1 作精确保序双拟合；相同校准分数聚合为权重，唯一查询分数有界缓存。不重训、不重新选择分割/阈值；融合与共形判断不变。应用推理标识为 r13-exact-va-v1，旧网格 API 仅保留供历史复现。
5. 独立源码包使用独立的清单和 SHA256，只列实际存在文件。明确不附运行时、wheel 和两个模型二进制；误用源码包启动时给出正确提示。
6. 更正整体完整性检查与应用降级的边界，写明特征 CSV、50 MiB / 50,000 行限制。
7. 历史浏览器验收脚本在无 Git 的源码快照目录中明确记录内容身份及空 git_head，避免启动监听归属测试在执行前因 git rev-parse 失败；监听归属与进程清理断言保留。
8. 隔离应用与跨进程重启测试的复制清单补齐两个新应用模块，保留原来的保存、拒绝、重启、导出及历史完整性断言。
9. 评测脚本区分使用测试标签作方向折叠的原始 AUC 与实际冻结 PAIC 输出 AUC；默认使用本版精确 VA，旧网格需显式开关，历史 JSON 保留原值并标注旧字段含义。模型/引擎均先校验再反序列化。
10. 旧生命周期测试夹具先等待真实子解释器就绪，再用标记 JSON 行读取 PID 身份，避免 Windows venv 关闭诊断混入日志导致解析失败；实际孤儿进程退出、无关进程保留等断言均保留。完整回归中该夹具失败与修订后定向复跑分别记录，不称作一次全绿。
